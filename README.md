# [Sketch](https://minuwu.github.io/Sketch/)

## Description

This project is a browser-based **Etch-a-Sketch inspired drawing application** built with vanilla JavaScript, HTML, and CSS. When the page loads, a grid of pixels is dynamically generated inside a container. As the user moves the mouse over these pixels, their background colors change according to dynamically updated RGB values, creating a flowing, colorful drawing effect. The app highlights efficient DOM manipulation, event-driven programming, and interactive user experiences without relying on external frameworks. 

[Play around here!](https://minuwu.github.io/Sketch/)
